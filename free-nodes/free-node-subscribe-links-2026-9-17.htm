Shadowrocket是一款专为iOS平台设计的网络代理软件，通过VPN、HTTP代理及多种协议支持，帮助用户实现流量加密、数据转发及访问控制。它不仅适用于科学上网，还能有效提升网络连接的稳定性和速度。

凭借高度的可定制性，Shadowrocket支持多种协议，包括Vmess、Shadowsocks（SS）等，允许用户根据实际需求灵活配置代理规则。此外，内置的实时流量统计和广告过滤功能，也让使用体验更加便捷和高效。

二、Shadowrocket的主要功能介绍

  1. 多协议支持
    支持Vmess、Shadowsocks（SS）、HTTP、HTTPS等多种网络协议，满足不同场景需求。

  2. 灵活的代理规则
    用户可以自定义访问规则，实现流量分流、过滤广告和屏蔽不良内容，提升浏览体验。

  3. DNS配置管理
    内置DNS代理，确保域名解析安全，避免DNS泄露。

  4. 实时流量监控
    提供流量使用统计，让用户清楚掌握代理流量的消耗情况，合理安排网络资源。

  5. 节点管理
    支持添加多个代理节点，方便用户切换，优化访问速度。

FAQ

PassWall2 在路由器上使用 TUN 模式会有什么影响？
启用 TUN 模式会拦截并转发路由器上全部或选定流量，这会增加路由器 CPU 与内存负担，可能影响路由器其他服务表现。建议在性能足够的设备上启用，或仅对特定设备/端口进行分流。
Nekoray 的订阅更新机制如何运作？
Nekoray 可以通过远程订阅 URL 自动下载最新节点和规则文件。用户可以设置更新频率，程序会定时检测并替换旧节点，保持配置最新状态。
Clash 的节点健康检测如何工作？
Clash 会定期对每个节点进行延迟和丢包率测试，并根据结果标记节点健康状态。结合策略组，可以自动切换到最优节点，避免访问高延迟或失效节点，提高整体网络稳定性和效率。
如何安全地共享订阅链接而不泄露个人信息？
避免将私人订阅直接在公开场合分享，若需要共享可在服务端生成只读或限速专用订阅，并定期更换 token。对外公开时移除或隐藏用户识别字段，确保他人无法通过订阅追溯出个人账户信息。
Netch 的全局代理与规则代理有何不同？
全局代理将所有流量都通过节点转发，而规则代理只针对指定 IP、端口或应用。全局代理适合游戏和全局科学上网，规则代理适合优化带宽和分流特定流量。
Clash 的策略组如何提升分流效率？
策略组可以将多个节点或规则组合在一起，实现按条件自动选择最佳节点。通过策略组，用户无需手动切换节点即可根据延迟、地理位置或流量类型自动分流，提高网络效率。
SSR 的混淆插件如何增强隐蔽性？
混淆插件可模拟正常协议特征，如 HTTP 或 TLS 流量，使 SSR 流量难以被检测。合理选择混淆方式和协议，可提升在高封锁环境下的长期稳定性和安全性。
SSR 的协议参数和混淆参数如何配置最安全？
选择 AEAD 或协议插件可提升安全性，混淆方式如 tls1.2_ticket_auth 可以模拟正常 HTTPS 流量。合理搭配协议和混淆参数，能够有效抵御 DPI 检测和流量封锁。
VMess 节点使用 AEAD 加密有何优势？
AEAD 加密能提供更强的安全性和抗重放能力，同时减少加密头泄露特征。相比普通加密，更适合高封锁环境，兼顾安全与性能，保证长期稳定使用。
Hiddify Next 用户带宽限制如何配置？
管理员可设置每个用户上传、下载和总流量上限，超出限制可自动降速或阻止访问。保证服务器资源合理分配，避免单用户占用过多带宽，提高整体网络公平性。
